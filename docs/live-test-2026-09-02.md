## The comparison — paper vs live

This is the whole point, so be precise about what transfers and what does not.

**Cannot be compared.** P&L, win rate, hold time, claimed-vs-realised, round-trip count. All
sandbox versions of these are artifacts of fabricated fills. Yesterday's −$95 over 64 trips
measures nothing.

**Can be compared — mechanics.** These behaved correctly on sandbox and must behave identically
live: contract arming and selection, preview→place→fill, reconciliation, both streams, the
role/window/cap gates, adoption, the halt.

**The one new measurement.** `session_report.py` check 1 compares the price the engine decided
on against the price it filled at. On sandbox it is **guaranteed** to diverge (verified: engine
priced `SPY260901P00765000` at ~2.34 at 12:20:45 ET; the tape traded 2.305 that minute; sandbox
"filled" at 1.20). On live those two come from the same system, so they should converge.

> **This is the pass/fail of the day.** Check 1 dropping from 100% mismatched to near zero is the
> result. It is also the first time the number has ever meant anything.

Run it against live data at the close:

```bash
./venv/bin/python scripts/session_report.py --date 2026-09-02 --env DEV
```

The script reads `TRADIER_ENV` to decide whether to label checks 1 and 2 diagnostic. If you run
live with `TRADIER_ENV` still set to `sandbox`, it will mislabel them — set it to `live` or read
past the label.
