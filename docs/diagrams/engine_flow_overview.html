Entry path · buy

1. Market tick arrives
tradier_stream_manager.py → stream_driven_worker.py
  • Tradier WS pushes quote/trade for symbol
▼
2. Entry-window gate
signal_generator.py:114–150
  • Strategy: open + entry_after_open_minutes
  • Account: user.trading_window_start (if enabled)
  • Effective start = LATER of the two (never widens)
  • If now >= trading_window_end → block entry
▼
3. Signal indicators
signal_generator.check_entry_signal:152–270
  • EMA(9): price > EMA (long) or < EMA (short)
  • VWAP: price on the right side of VWAP
  • Volume spike: vol / avg20 >= min_volume_multiplier
  • Delta in [delta_min, delta_max]
  • Liquidity: open_interest, bid-ask spread
  • $TICK (optional, off by default)
  • Confirmation: ≥2 indicators must align
▼
4. Risk validation
risk_manager.validate_pre_trade:109–218
  • Strategy active? Mode matches user?
  • Account-wide daily loss cap (sum of realized + unrealized)
  • Strategy daily loss · max drawdown
  • Position cap: count of open (strategy, symbol) rows
  • Size sanity: qty ≤ calculated_qty × 1.5
All loss caps are entries-only: side='sell' is auto-approved.
▼
5. Role gate
order_manager.execute_signal:416–439
  • Buys: only user or admin
  • Blocks: viewer, auditor, strategy_author
  • Sells bypass this gate — closeable on demotion
▼
6. Lock-out + rate limit
order_manager.py:442–502
  • Existing position on (user, strategy, symbol) → skip entry (row lock)
  • Per (user, symbol) throttle: 5.0 s minimum interval
▼
7. CASH / GFV GATE ★
order_manager._preview_or_abort:298–382
  • Tradier preview returns cost (= order_cost + commission + fees)
  • Fetch balances.cash.cash_available (settled cash only)
  • Sandbox adds fee_buffer = qty × $0.65 (parity with live)
  • required = cost + fee_buffer
  • effective_avail = settled_cash − Σ pending reservations
  • If required > effective_avail → REJECT
  • Else: acquire reservation UUID (60 s TTL), proceed
This is what prevents GFV: buying with unsettled funds is impossible because cash_available already excludes them.
▼
8. Place order
trading_client_manager → Tradier (or Alpaca paper)
  • Market order; routed by user.selected_trading_mode
▼
9. Poll fill
order_manager.py:543–607
  • Loop until terminal: filled / rejected / canceled / expired
▼
10. Record + reconcile
order_manager.py:609–674
  • Insert Trade row
  • Create/update Position (the source of truth for "are we long X")
  • finally: release reservation UUID

Exit path · sell

Open position
Position row · peak_price / trough_price tracked per tick
▼ each tick
check_exit_signal
signal_generator.py:298–457
First trigger wins. Order matters:
  • 1. Take profit: pnl_pct ≥ TP%
  • 2. Stop loss: pnl_pct ≤ −SL%
  • 3. Trailing stop: after pnl_pct ≥ activation, exit if price ≤ peak × (1 − dist/100)
  • 4. Max hold time: elapsed ≥ max_hold_minutes
  • 5. Time of day: EARLIEST of close − exit_before_close_minutes and user.trading_window_end
▼ sell signal
close_position
order_manager.py:1084–1346
  • Same rate limit, preview path
  • No role gate · no cash gate · no daily-loss block
  • Sells generate cash → never insufficient-cash rejected
▼
Fill → position.qty = 0
order_manager.py:1200–1297
  • Reconcile exit reason
  • P&L realized into account

Composition rule

  • Entry windows: most-restrictive wins (LATER start, EARLIER end).
  • Caps: account-wide cap is checked before strategy cap.
  • Exits: every entry gate falls through for sells.

Verify by hand — circle ✓ / ✗ and annotate

Buys check settled cash (cash.cash_available), not total/margin BP. Sells skip role gate, cash gate, daily-loss cap. (exits sacred) Concurrent buys: 2nd signal sees subtracted effective_avail. (no double-spend) Entry window: max(strategy_start, account_start). Exit: min(strategy_end, account_end). Reservation released in finally on every terminal outcome. TTL safety belt: 60 s expiry logs a warning if release path was missed.

Sanity checks — circle ✓ / ✗ and write the why

SPY R:R is 1:2 (lose $1 to gain $0.50). Win rate > 67% needed for positive expectancy. Hit rate target? TSLA R:R is 1:1.33 — needs >57% hit rate. Aligns with higher vol & tighter SL. Trailing activation < TP for both (SPY 15<25, TSLA 20<30). Trail only kicks in if a TP miss starts pulling back. Max position $ vs risk %: at $1k account, SPY 1.5% = $15 risk, $500 size → tolerates 3% adverse before stop. Max hold (30m / 20m) vs 0DTE theta decay (steepens after 2pm): are these tight enough? TSLA max_positions = 1: prevents stacking single-name concentration. Volume spike multiplier higher on TSLA (2.5 vs 2.0): demands clearer momentum confirmation.
