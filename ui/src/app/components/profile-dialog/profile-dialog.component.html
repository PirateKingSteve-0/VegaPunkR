Risk limits

Daily loss halts new entries account-wide once today's realized + unrealized loss reaches this percentage of your account size. Existing positions stay closeable; the cap resets at midnight ET. Account size and max trade size drive position sizing.

When enabled, no entries fire before start or after end, and any open position is force-exited at end. The strategy's own opening-noise and exit-before-close rules still apply — the more restrictive bound wins.
